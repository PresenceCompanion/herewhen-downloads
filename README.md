# HereWhen Co-pilot downloads

The HereWhen desktop co-pilot is a small window for Mac and Windows. It floats over your video or game so your Anime Buddy or Player Two can react while you watch or play.

Get the latest installers from the [Releases](../../releases/latest) page.

## First launch

These early builds are not code-signed yet, so your computer will ask you to confirm once.

- **Mac:** open the .dmg and drag the app to Applications. If macOS says it cannot verify the developer, right-click the app, choose Open, then Open again. The first time you pick a window, allow Screen Recording in System Settings > Privacy & Security.
- **Windows:** run the installer. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.

## Linking

In the HereWhen app, open your Anime Buddy or Player Two and tap **Get link code** on the Desktop co-pilot card, then type the code into the desktop app.
